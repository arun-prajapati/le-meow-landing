How the features work

The October guide records local testing for these workflows. It identifies new-booking alerts as already live at that date.

Product pickup

Customers choose a collection place and time for brands that enable pickup. The guide uses Madbakes and Meow Luxury as examples. Pickup has no shipping fee and can apply a brand-configured discount.

Pickup settings and staff offers

Admins manage shared locations and set each brand’s locations, times and fixed or percentage discount. Admins can create pickup orders in the web or mobile app. Staff can send a Meow Luxury pickup offer and change fulfilment before payment. The server validates the location, time and discounted total.

Pickup walkthrough · pp. 2–7 →

Revenue and customer activity

Admin web counts direct payments and paid wallet top-ups as revenue. It reports manual wallet credits separately and counts wallet-funded spend once, at top-up.

Wallet reporting and in-app behaviour

Wallet cards appear in All Brands. Activity reports show events by day, weekday and hour in Singapore time. The updated customer app records signed-in visits, time on screens and paths between screens. Named button actions remain an open item in the guide.

Dashboard walkthrough · pp. 8–10 →

Appointment slot limits

Admins set a capacity for a time slot or whole day by brand or outlet. Customers and staff receive a message when a booking reaches a full slot. Admins can confirm a “Book anyway” override.

Capacity rules and rescheduling

Limits can cover a date or date range. Zero closes a slot or day. Paid, active appointments count toward capacity and cancellations and rejections free places. Multi-child bookings count one place per child. The admin confirmation also applies when rescheduling.

Slot limits walkthrough · pp. 11–15 →

Gift vouchers and occasions

Customers pick an occasion, an amount and a recipient. Admins manage a shared list of voucher amounts and give each occasion its own banner, tagline and sale dates.

Complimentary vouchers and reporting

Admins can preview and issue a gift to up to 200 customers. Recipients see it in My Vouchers and get a notification. The Admin Gifts report tracks gift value, redemption and expiry separately from paid sales. Existing occasion settings carry into the new setup.

Gifting walkthrough · pp. 16–24 →

Buddy Push, Team Target and Top 3

Staff Home shows pair progress, the weekly team target and the three highest sellers. Admins can pair staff manually or automatically and set an equal cash or points reward for each buddy.

Sales, rewards and weekly settlement

Eligible paid package sales count after refunds. A challenge can use a fixed pair target or the sum of both weekly targets, with an optional minimum per buddy. Weekly settlement freezes results and notifies winners. Cash flows to Weekly Incentives in web payroll. Automatic settlement requires the server scheduler.

Staff incentives walkthrough · pp. 25–33 →

New-booking alerts

Admins see a new-booking banner and a Bookings badge in the Admin app, plus an Orders badge in Admin web. Each admin can mark their unseen bookings as seen.
